# Technical LinkedIn Post Formatter

Herramienta de estructuración y formateo de publicaciones técnicas para LinkedIn, diseñada para optimizar la legibilidad, retención y distribución de contenidos de ciberseguridad e ingeniería.

---

## Arquitectura y Componentes

- **Estructura:** Formato Hook-Valor-CTA calibrado entre 1.200 y 1.800 caracteres.
- **Reglas de estilo:** Eliminación de expresiones infladas y alineación con criterios de redacción directa.
- **Etiquetado:** Curaduría temática de etiquetas (#Ciberseguridad, #ThreatIntelligence, #DevSecOps).

---

## Instrucciones de Uso

Consulte los ejemplos y utilitarios de formateo en la carpeta `docs/`.

---

## Consideraciones de Seguridad

- Este repositorio almacena código fuente, utilitarios de prueba y documentación técnica de ingeniería.
- Todas las credenciales, llaves privadas y variables de entorno deben suministrarse de forma local mediante archivos no versionados.
- Las herramientas de auditoría contenidas deben utilizarse exclusivamente en entornos autorizados y laboratorios de prueba.
